# Aether Dashboard

A clean, modern, institutional-style data analytics dashboard built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

Designed with a soft **Sage Green** color theme for a professional and calm look — perfect for data products and internal tools.

**Live Demo:** Coming soon (Vercel)

---

### Features

- Responsive sidebar (collapses on mobile)
- Top navigation with search and notifications
- 4 Overview metric cards with trend indicators
- Interactive line chart (Data Ingestion Over Time)
- Interactive bar chart (Sources Breakdown)
- Data Sources table with status badges
- Recent Activity feed
- Soft Sage Green institutional design system
- Fully responsive (Desktop → Tablet → Mobile)

---

### Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **Utilities:** clsx + tailwind-merge
